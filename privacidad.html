Política de Privacidad

Tu privacidad y la gestión de datos en este rediseño conceptual.

AVISO DE SEGURIDAD: Los formularios de esta web son simulados. Ninguno de los datos de contacto (nombre, teléfono o dirección de correo electrónico) introducidos en los formularios se almacena en base de datos, ni se envía a terceros, ni se utiliza con fines comerciales reales.

1. Carácter Demostrativo y de Simulación

Esta web ha sido diseñada exclusivamente como un caso de estudio y ejemplo interactivo de diseño web avanzado. La cumplimentación del diagnóstico interactivo y el formulario de solicitud finalizara con una respuesta de éxito simulada en la interfaz del cliente.

Ningún dato es procesado por servidores remotos. Toda la gestión del flujo del formulario se ejecuta directamente en el navegador del usuario (en el cliente) mediante código Javascript, sin persistir ni registrar la información introducida.

2. Recopilación de Datos

En consecuencia con su naturaleza demostrativa, no recopilamos de forma automatizada ni estructurada ninguna información personal identificativa de las personas que naveguen por este sitio web de portfolio.

3. Enlaces a Terceros

Esta demo es completamente independiente. El objetivo es mantener una experiencia de navegación autónoma y cerrada dentro de este entorno visual rediseñado. Los enlaces externos están reducidos a los estrictamente necesarios para simular los canales de comunicación tradicionales (correo electrónico ficticio y teléfono de contacto del despacho real).

4. Contacto Real

Si desea contratar servicios jurídicos o contactar de forma real con el despacho original Clavería Abogados, le invitamos a visitar sus oficinas físicas o sus canales corporativos oficiales fuera de esta plataforma de diseño conceptual.
